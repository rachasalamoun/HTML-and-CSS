# HTML-and-CSS

This repository contains a modern, colorful personal portfolio website built using **HTML5** and **CSS3**.

## Projects Included
1. **Bootstrap Project**: A responsive layout built using the Bootstrap framework (referenced as part of the curriculum).
2. **Personal Portfolio**: A custom-styled webpage showcasing advanced CSS techniques including video backgrounds, overlays, and fixed navigation.

## Features Demonstrated
- **Navigation**: Fixed top menu with hover effects.
- **Multimedia**: Autoplaying, muted, looping background video with text overlay.
- **Image Manipulation**: CSS filters, rounded corners, and centered placement.
- **Interactive UI**: Image overlay fade effects and paragraph hover states.
- **Layouts**: Standardized two-column grid and styled data tables.
- **Footer**: Centered and bolded professional footer.
